# Adventure entries, one file each

Entries 7 and later live here. Each file is one block, starting with `<div class="adventure">` and ending with its matching `</div>`, named `NN-slug.html` so they sort oldest first. Push, and the deploy places them on the page at the `ADVENTURES:ADDON` marker in `adventures/index.html`. That page in the repo is never edited to add an entry, so it can't be overwritten by accident.

Photos go in `adventures/img/adv<N>/`, about 1000 px wide, location data stripped.

Copy `07-wonderland.html` for the shape. Full steps: the repo README, "Adding an adventure".
